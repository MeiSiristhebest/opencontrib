# @opencontrib/cli

> The Deterministic Open-Source Contribution Engine CLI for Autonomous AI Coding Agents.

## Installation

```bash
# Global install via npm
npm install -g @opencontrib/cli

# Run directly via npx
npx -y @opencontrib/cli doctor
```

## Quick Start

```bash
# 1. Check local environment and probe toolchains
opencontrib doctor --pretty

# 2. Initialize a contribution run
opencontrib run create --repo <owner/repo> --issue <issue_id>

# 3. Follow deterministic NEXT RECOMMENDED COMMAND outputs
```
