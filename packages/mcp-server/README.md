# @opencontrib/mcp

> OpenContrib Model Context Protocol (MCP) Server — 41 Composable Domain Tools for AI Agents.

## Quick Start

### Claude Code

```bash
claude mcp add opencontrib npx -y @opencontrib/mcp
```

### Cursor

Add to `.cursor/mcp.json` or `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "opencontrib": {
      "command": "npx",
      "args": ["-y", "@opencontrib/mcp"]
    }
  }
}
```

### Automated Setup

Auto-configure across all detected IDEs & agents:

```bash
npx -y @opencontrib/mcp setup --all
```

## Capabilities

- **41 Composable Tools**: Defect probes, smart pointers, worktree sandboxing, dual-stage empirical evidence, RFC-100 governance audit, PR submission.
