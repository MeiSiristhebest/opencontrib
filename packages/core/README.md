# @opencontrib/core

> Agent-Native Open Source Contribution Engine — Core domain algorithms, governance verification & risk engine.

## Installation

```bash
npm install @opencontrib/core
# or
bun add @opencontrib/core
```

## Modules

- `@opencontrib/core`: Core domain microkernel and orchestration
- `@opencontrib/core/probe`: 6-dimension defect probes and triage
- `@opencontrib/core/workspace`: Clean-room Git worktree sandboxing
- `@opencontrib/core/evidence`: Dual-stage RED/GREEN verification
- `@opencontrib/core/governance`: RFC-100 anti-AI governance gate
- `@opencontrib/core/llm`: Unified dynamic prompt engine and LLM services
